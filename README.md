# take_home_assignment

Run the files critical_membership_main and critical_role_main for the output.
You will need an API key for tavilly, diffbot and OpenAi. 
Running the files mentioned above will automatically setup the database, there is no need to set it up separately. 
The run might take a while for each organization, please be patient!
The reports for each organization and membership are present as txt files in the folders critical_memberships and critical_role_evidences.
